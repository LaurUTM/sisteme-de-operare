# sisteme-de-operare
IA-241 2026 - Sisteme de operare

## Fitness Tracker (laborator - timere)

- `WorkoutTimer` - timer crescator: durata antrenamentului + calorii arse
- `RestTimer` - timer descrescator: pauza de 60s intre seturi
- `Main` - fereastra si apelurile catre timere

### Rulare

```bash
cd fitness-tracker
javac -d out src/*.java
java -cp out Main
```
